## Recommended sizes
- Cover images: 800×1000px (portrait, 4:5) or 1600×900px (for featured wide cards)
- Hero images: 1400×600px minimum (16:9 recommended)
- Gallery images: 1200×900px (4:3 recommended)
- Portrait: 960×1200px (4:5 portrait orientation)

## Notes
- All images are lazy-loaded except the case study hero
- Images render with `object-fit: cover` — you can use any crop
- Missing images show the dark surface background gracefully
- To add a project, add its entry to `data/projects.json` only — no HTML changes needed
